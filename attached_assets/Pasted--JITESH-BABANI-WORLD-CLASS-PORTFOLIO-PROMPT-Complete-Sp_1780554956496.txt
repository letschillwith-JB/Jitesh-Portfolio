## DESIGN DIRECTION

### Aesthetic: "Focused Craft"

Think: Linear.app meets a boutique software consultancy.
Dark-first. Not gamer-dark — *architect-dark*. The darkness says *precision*, not *attitude*.

| Property | Direction |
|---|---|
| **Theme** | Dark base (#0A0A0F), not pure black |
| **Accent** | Electric indigo (#6366F1) with a subtle teal secondary (#14B8A6) |
| **Surface** | Layered dark cards (#111118, #16161F) with 1px subtle borders |
| **Typography — Display** | `Syne` (Google Fonts) — geometric, confident, modern |
| **Typography — Body** | `DM Sans` — clean, readable, not generic |
| **Typography — Mono** | `JetBrains Mono` — for code snippets and tech labels |
| **Radius** | 12px standard, 8px small, 20px large cards |
| **Motion** | Framer Motion — ease-out, 0.4–0.6s duration. Never bouncy. |
| **Grid** | max-w-7xl centered, 5% horizontal padding on mobile |

### Glassmorphism: Used Surgingly
Only on hero floating cards and feature callout boxes. Rule: if removing the glass effect loses nothing, remove it. Use `backdrop-blur-xl bg-white/5 border border-white/10`.

### Gradient Strategy
- **Hero gradient:** Radial from indigo at 20% opacity, fading to transparent — like a halo, not a rainbow.
- **Cards:** Subtle `linear-gradient(135deg, #111118, #16161F)` — just enough to feel crafted.
- **No gradient text** except for the hero headline. One uses of it, maximum.

### What to Avoid
- Purple-on-purple anything
- Floating orbs and blobs (amateur)
- Skill progress bars
- "I am a passionate developer" copy
- Technology logo walls
- Timeline-style "My Journey" sections
- Any design pattern seen on a Figma community freebie

## ANIMATIONS SPEC (Framer Motion)

**Rule:** Every animation must serve the content, not distract from it.

```typescript
// Standard page entry for sections
const sectionVariants = {
  hidden: { opacity: 0, y: 30 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.5, ease: "easeOut" }
  }
};

// Stagger children (for feature cards, skill groups, etc.)
const containerVariants = {
  hidden: {},
  visible: {
    transition: { staggerChildren: 0.1 }
  }
};

// Trigger: whileInView with once: true
// viewport: { once: true, margin: "-100px" }
```

**Specific animations:**
- Hero headline: `clipPath` reveal from bottom — each word, staggered 0.05s
- Hero dashboard widget: `fadeInUp` at 0.6s delay after headline
- Nav: No animation on load. Blur/opacity background triggers on scroll only.
- Project cards: `fadeInUp` stagger as grid enters viewport
- Process steps: `scale` from 0.9 to 1 + `fadeIn` per step, staggered
- CTA band: Text `fadeInUp` only. No parallax.
- Footer: No animation. Just renders.
